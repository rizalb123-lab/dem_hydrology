about=DEM Hydrology Toolkit computes every hydrology analysis that can be derived from a DEM alone, with the original (English) analysis names: Fill Sinks (Priority-Flood), depressions, slope, aspect, hillshade, curvature, TPI, TRI, landform classification, flow direction and accumulation (D8, D-Infinity, MFD), flow length, stream network with Strahler order and Shreve magnitude, sub-watersheds, watersheds from pour points, basin morphometry and hypsometry, TWI, SPI, STI, LS factor (RUSLE), HAND, drainage density, travel time / isochrones, HAND flood and bathtub inundation, and composite flood-susceptibility, recharge-potential and erosion-susceptibility indices. Every output is styled automatically, drawn on a standard map (legend, scale bar, north arrow, administrative boundaries and labels), and summarised in an Excel workbook and a PDF report. Each analysis lists its formula, limitations and scientific references, and all parameters are user-editable. The interface and reports are multilingual (English, Indonesian, Spanish, French, Portuguese); users can add or edit languages by dropping a JSON file in the language folder. Requires numpy and scipy (bundled with QGIS); openpyxl is needed for the Excel report. Free to use; support the author at https://sociabuzz.com/rizalb123
